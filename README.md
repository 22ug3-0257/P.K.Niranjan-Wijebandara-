## Project Description

This is a Java console application developed to simulate a
mini hospital emergency management system.

## Data Structures Used

- Binary Search Tree for patient records
- Queue for emergency patients
- Stack for completed treatment records
- Singly Linked List for patient visit histories

## Main Features

- Register a patient
- Search for a patient
- Delete a patient
- Display patients in ascending Patient ID order
- Add patients to the emergency queue
- Treat the next emergency patient
- Store completed treatments
- Add, search, remove and display patient visits

## How to RunS

1. Open the project using Eclipse.
2. Open HospitalManagementSystem.java.
3. Select Run As > Java Application.
4. Use the menu displayed in the Console.
